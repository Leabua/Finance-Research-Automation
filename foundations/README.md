# Spreadsheet foundations

[Standards and Curves (.ods)](Standards-and-Curves.ods) is the earlier spreadsheet work labelled “pre-ai” in the original collection. It contains standardised financials and J-curve work for Calgro M3 and Stefanutti Stocks, including the order book, infrastructure pipeline, Bankenveld, Memorial Parks, Fleurhof and South Hills.

The workbook is preserved in its original OpenDocument format. It contains historical external links to files on the original machine, so those links cannot refresh from this repository. For the main portfolio models, use the [Calgro Excel model](../research/calgro-m3/models/CGR-Full-with-Models.xlsx) and [SSK Excel model](../research/stefanutti-stocks/models/SSK-Full-Model.xlsx).
